# 接入 AI 订阅与本地网关（内置 GPT-Load）

MAVO BOX 的安装包**内置**了开源本地网关 [GPT-Load](https://github.com/tbphp/gpt-load)（MIT 许可）。把它放在中间，你就能：

- 把**多个 API Key** 合并成一个入口，自动轮询、失败切换、统计用量；
- 把**订阅账号**（GPT-Load 自带 Codex、Claude、Antigravity、Grok 等订阅渠道）当作大模型来用；
- 软件里只需要一个地址和一个 AccessKey，之后换渠道、换账号都在网关控制台里改。

每次打包安装包时，构建流程都会自动取 GPT-Load 的**最新发布版**，并用它发布页的 SHA-256 校验后才放进安装包；具体版本显示在「AI 订阅」页里。

## ⚠️ 使用订阅账号前请先看这一段
- **可能违反服务商的使用条款**：很多订阅（如 ChatGPT、Claude、Gemini 的个人订阅）的条款并不允许通过第三方程序或网关当作 API 使用，存在**限流、封号**的风险。各家条款会变化，请自行到官网核对，本手册不保证其当前是否允许。
- **只用你自己的账号**，不要使用来路不明的账号或共享账号，也不要把网关的 AccessKey、管理 Key 分享给别人。
- 订阅通常**不按量计费但有额度和速率限制**，大批量生成时可能被限速；稳定性不如正式 API Key。
- 想要稳定、可核算费用，请优先使用**服务商官方的 API Key**（同样可以放进网关里统一管理）。
- GPT-Load 的 2.x 在其官方说明里仍属 Beta / RC 阶段，功能和界面可能变化。
- 内置网关**默认关闭**，只监听本机 `127.0.0.1`，不会被局域网或公网访问。

## 使用内置网关（推荐）
**每个页面顶部都有一个 "GPT-Load 网关" 开关条**（右侧是状态和版本）：

1. 拨动开关即可启用/关闭内置网关（启用后会随软件自动启动；首次启动最多约 40 秒）。状态变成"运行中"后会显示内置的 GPT-Load 版本。
2. 点 **"复制登录 Key"**，再点 **"打开 GPT-Load"**：控制台会在**应用内的独立窗口**里打开（不是浏览器），把 Key 粘贴到登录页即可。Key 保存在系统凭据管理器里，不要发给任何人。关闭这个窗口不会停止网关；关闭主窗口则整个软件和网关一起退出。

「AI 订阅」页里有同样的按钮，另外还有"用系统浏览器打开"和下面第 4 步的接入表单。
3. 在控制台里依次完成：**添加渠道**（填 API Key；订阅渠道按提示完成授权）→ **创建分组**（选渠道、配置模型）→ **创建 AccessKey**，复制这个 AccessKey。
4. 回到「AI 订阅」页，把 AccessKey 粘贴进去，点 **"连接到 MAVO BOX"**。设置页里就会出现"本机网关（内置 GPT-Load）"，作为**大模型 LLM** 使用。
5. 到 **「设置」** 页，在它旁边点 **"测试连接 / 获取模型"**，列表里点一下就选用某个模型。

> 网关的数据（数据库、`auth.key`、`encryption.key`）在数据目录的 `gateway/` 文件夹里。**备份时数据库和 `encryption.key` 必须一起保管**，丢了 `encryption.key`，已保存的渠道凭据就无法恢复。网关日志在 `gateway/logs/gpt-load.log`。

> 订阅渠道的 OAuth 使用固定回调端口（1455、54545、51121），如果你电脑上同时在用 Codex CLI 等工具，端口可能冲突。内置网关本身使用端口 **31001**（可用环境变量 `MAVOBOX_GATEWAY_PORT` 修改），不会和你自己装的 GPT-Load（默认 3001）冲突。

## 能用在哪些功能上
| MAVO BOX 功能 | 通过网关 | 说明 |
|---|---|---|
| 大模型 LLM（视频理解、脚本、混剪编排） | ✅ | 视频理解需要所选模型**支持图片输入** |
| 配音 TTS、图片生成 | 视渠道而定 | GPT-Load 的 OpenAI 入口提供 `/v1/audio/speech`、`/v1/images/...`，要看你配置的渠道是否支持 |
| 语音转写 ASR（`/audio/transcriptions`） | ❌ 一般不行 | 建议单独配置 OpenAI 官方的转写服务；没有 ASR 时克隆功能会按字符估算词级时间 |
| 视频生成（fal.ai、Replicate 等） | ❌ 不经过 | 视频生成接口是任务队列式协议，请直接在 MAVO BOX 里配置 |

## 费用估算
订阅渠道不按量计费，MAVO BOX 无法知道单价，会显示"价格未知"。想去掉这个提示，可在该服务的"高级配置"里填 `{"pricing": {"per_request": 0}}`（表示按次 0 元）。真实成本、额度和用量请以网关的用量统计和订阅方的后台为准。

## 想用自己装的 GPT-Load（或其他 OpenAI 兼容网关）
不想用内置的，也可以连你自己安装的网关：向导或设置里选 **"本地网关 / 订阅接入"** 预设，地址填你的网关 `/v1` 地址（自装 GPT-Load 默认 `http://127.0.0.1:3001/v1`），Key 填 AccessKey，再点"测试连接 / 获取模型"。官方发布页：<https://github.com/tbphp/gpt-load/releases>（请核对其中的 `SHA256SUMS`）。

## 常见问题
- **启用后状态一直不是"运行中"**：看「AI 订阅」页的报错。常见原因：端口 31001 被占用；杀毒软件拦截了 `gateway\gpt-load.exe`（把安装目录加入信任名单）。
- **提示"这个安装包里没有内置网关程序"**：请重新下载最新的安装包。
- **401 / Key 无效**：填的是网关的 **AccessKey**，不是上游的 API Key，也不是管理 Key；并确认它允许访问对应分组。
- **模型列表是空的**：分组里还没配置模型。
- **想让别的电脑也能用这个网关**：不建议。保持只监听 `127.0.0.1`，网关一旦暴露到局域网或公网，等于把你的订阅和 Key 公开。

## 给发行者：打包时的版本策略
- `scripts/build.cmd`（macOS 用 `scripts/build.sh`）每次都会先运行 `scripts/fetch_gptload.py`：
  1. 读取 GitHub 上 GPT-Load **最新发布版**（维护者标记的 latest）；
  2. 下载对应平台的程序，并**用同一发布页的 `SHA256SUMS` 校验**，校验失败不会使用、不会覆盖旧文件；
  3. 已是最新就不重复下载；同时保存该版本的许可证文件，随安装包发出；
  4. 版本号、来源、SHA-256 记录在 `vendor/gpt-load/VERSION`，打进安装包的 `gateway/VERSION`。
- **无法确认最新版本（断网、被限流）时打包会失败**，而不是悄悄带上旧版。仅在离线实验时设 `GPTLOAD_ALLOW_STALE=1` 才会改用本地旧版（并警告）。
- 最新版的主版本号不是 2 时（可能与本应用的接入方式不兼容）打包会停止，需要人工确认后再调整。
- 网络很慢时可以自己用浏览器下载发布页里的 `gpt-load-windows-amd64.exe`，再运行 `python scripts/fetch_gptload.py --from-file <下载好的文件>`：脚本同样会用官方 `SHA256SUMS` 校验。
