# 接入 AI 订阅与本地网关（GPT-Load 等）

MAVO BOX 的"大模型"可以连到任何 **OpenAI 兼容**的地址。把一个本机 AI 网关（例如开源项目 [GPT-Load](https://github.com/tbphp/gpt-load)，MIT 许可）放在中间，你就能：

- 把**多个 API Key** 合并成一个入口，自动轮询、失败切换、统计用量；
- 把**订阅账号**（GPT-Load 自带 Codex、Claude、Antigravity、Grok 等订阅渠道）当作大模型来用；
- 软件里只需要填一个地址和一个 Key，之后换渠道、换账号都在网关里改，不用动 MAVO BOX。

> MAVO BOX **没有内置**网关，也不会替你登录任何订阅账号。网关是一个独立的程序，装在你自己的电脑上、由你自己配置。

## ⚠️ 使用订阅账号前请先看这一段
- **可能违反服务商的使用条款**：很多订阅（如 ChatGPT、Claude、Gemini 的个人订阅）的条款并不允许通过第三方程序或网关当作 API 使用，存在**限流、封号**的风险。各家条款会变化，请自行到官网核对，本手册不保证其当前是否允许。
- **只用你自己的账号**，不要使用来路不明的账号或共享账号，也不要把你的网关地址和 AccessKey 分享给别人。
- 订阅通常**不按量计费但有额度和速率限制**，大批量生成时可能被限速；稳定性不如正式 API Key。
- 想要稳定、可核算费用，请优先使用**服务商官方的 API Key**（也可以放进网关里统一管理）。
- GPT-Load 的 2.x 在其官方说明里仍属 Beta / RC 阶段，功能和界面可能变化。

## 第一步：安装并启动 GPT-Load
1. 到官方发布页 <https://github.com/tbphp/gpt-load/releases> 下载你系统的版本（Windows 可选 `gpt-load-windows-setup.exe`，会装成开机自启的服务；也有免安装的便携版）。**请核对发布页里的 `SHA256SUMS`。**
2. 默认只监听本机 `127.0.0.1:3001`。浏览器打开 <http://127.0.0.1:3001>，用首次启动生成的**管理 Key** 登录（安装程序结束前会显示，请保存；Windows 服务版的副本在 `%ProgramData%\GPT-Load\data\auth.key`）。
3. 在网关控制台里依次完成（详见 GPT-Load 官方说明）：
   1. **添加渠道**：选择上游，填 API Key；订阅渠道按提示完成 OAuth 授权。
   2. **创建分组**：选渠道，配置可用的模型。
   3. **创建 AccessKey**：设定允许的分组和协议，复制生成的 AccessKey。
4. 备份时，数据库和 `encryption.key` **必须一起保管**，丢了加密的凭据就无法恢复。

> 订阅渠道的 OAuth 使用固定回调端口（1455、54545、51121），如果你电脑上同时在用 Codex CLI 等工具，端口可能冲突。

## 第二步：在 MAVO BOX 里连上网关
1. 打开 **向导**（或 **设置**），服务类型选 **"本地网关 / 订阅接入（GPT-Load 等 OpenAI 兼容网关）"**。
2. 接口地址保持 `http://127.0.0.1:3001/v1`（端口改过就对应修改），**API Key 填网关里创建的 AccessKey**，保存。
3. 到 **设置** 页，在刚添加的服务上点 **"测试连接 / 获取模型"**：
   - 成功会列出网关里可用的模型，**点一下就选用**；
   - 失败会给出原因：连不上 → 确认网关已启动；Key 无效 → 检查 AccessKey 和它允许的分组；没有 `/models` → 手动填写模型名。

## 能用在哪些功能上
| MAVO BOX 功能 | 通过网关 | 说明 |
|---|---|---|
| 大模型 LLM（视频理解、脚本、混剪编排） | ✅ | 视频理解需要所选模型**支持图片输入** |
| 配音 TTS、图片生成 | 视渠道而定 | GPT-Load 的 OpenAI 入口提供 `/v1/audio/speech`、`/v1/images/...`，要看你配置的渠道是否支持 |
| 语音转写 ASR（`/audio/transcriptions`） | ❌ 一般不行 | 建议单独配置 OpenAI 官方的转写服务；没有 ASR 时克隆功能会按字符估算词级时间 |
| 视频生成（fal.ai、Replicate 等） | ❌ 不经过 | 视频生成接口是任务队列式协议，请直接在 MAVO BOX 里配置 |

## 费用估算
订阅渠道不按量计费，MAVO BOX 无法知道单价，会显示"价格未知"。想去掉这个提示，可在该服务的"高级配置"里填 `{"pricing": {"per_request": 0}}`（表示按次 0 元）。真实成本、额度和用量请以网关的用量统计和订阅方的后台为准。

## 常见问题
- **连不上 127.0.0.1:3001**：网关没启动。命令行 `curl http://127.0.0.1:3001/health` 能返回 `ok` 才算正常。
- **401 / Key 无效**：填的是网关的 **AccessKey**，不是上游的 API Key，也不是管理 Key；并确认它允许访问对应分组。
- **模型列表是空的**：分组里还没配置模型。
- **想让别的电脑也能用这个网关**：不建议。保持只监听 `127.0.0.1`，网关一旦暴露到局域网或公网，等于把你的订阅和 Key 公开。
