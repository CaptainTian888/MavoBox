# MAVO BOX 学员手册

## 1. 安装
**Windows 10/11**：双击 `MAVO BOX_x.x.x_x64-setup.exe`，一路下一步。若出现"Windows 已保护你的电脑"，点 **更多信息 → 仍要运行**（安装包暂未购买代码签名证书，属正常现象）。
**macOS**：打开 `.dmg`，把 MAVO BOX 拖进"应用程序"。首次打开若提示"无法验证开发者"，在访达里**右键 → 打开**；仍被拦截时到 **系统设置 → 隐私与安全性 → 仍要打开**。

## 2. 激活（只需一次）
1. 首次启动会看到激活页，上面有你的**机器码**（形如 `ABCDE-12345-FGHIJ-67890`），点"复制"。
2. 把机器码发给老师，老师会回复一串以 `MAVO1.` 开头的**授权码**。
3. 把授权码粘贴进去，点"激活"。授权码绑定你这台电脑，不能给别人用；过期后联系老师续期。

## 3. 首次使用向导
激活后进入"向导"页：
- **视频处理组件**：安装包已内置，显示 ✅ 即可。
- **发布用浏览器组件**：只有用到"账号 / 发布"时需要。点"一键安装"，约 150MB。下载很慢或失败时，在"下载镜像"里填老师提供的地址再试。
- **AI 服务**：选择类型 → 填接口地址、模型和你自己的 API Key → 保存。Key 只保存在你电脑的系统凭据管理器里，不会显示、不会上传。没有的服务可以先跳过。

## 4. 功能一览
| 页面 | 做什么 |
|---|---|
| 下载 | 粘贴单个 TikTok 视频链接，下载并截取前 N 秒 |
| 素材库 | 登记本地视频/图片 |
| 混剪 | 选多个素材 + 写要求，AI 切镜头、编排时间线，渲染成 9:16 成片 |
| 爆款克隆 | 参考视频 + 你的产品/人物图 → 解读钩子 → 改写脚本 → 生成新镜头 → 合成 |
| 账号 | 添加 TikTok 账号、代理，登录一次保存登录态 |
| 发布 | 选视频、写文案和话题、定时，到点自动发布 |
| AI 订阅 | 页面顶部有"GPT-Load 网关"开关，一键启用软件内置的本地网关（GPT-Load）并在应用内窗口打开控制台，把你自己的 API Key 或订阅账号统一接入，当作大模型使用（订阅有违反服务商条款的风险，见页面提示） |
| 设置 | 管理各项 AI 服务的接口和 Key，可"测试连接 / 获取模型" |

## 5. 成片质检与遇到问题怎么办
- **成片质检**：渲染完成后点"成片质检"（素材库里每个视频也有这个按钮），会检查是不是竖屏 9:16、时长、黑屏、画面静止、静音、声音是否太小或爆音，并给出一张 12 帧的缩略图总览，发布前先扫一眼。提示只是参考，最终以你的观看为准。
- **遇到问题**：在"设置""向导"或激活页点 **复制诊断报告**，粘贴发给老师即可，里面不含你的 API Key、授权码和账号信息；也可以点"打开日志文件夹"找到日志文件。
- **软件打不开 / 一直白屏**：窗口里会显示启动失败的原因和排查步骤，按提示处理，仍不行再把日志发给老师。

## 6. 费用与安全
- **生成类接口按量收费**，费用由你自己的 API 账号承担。生成前软件会给出费用估算，**确认金额后才会真正调用**；价格未知的服务会提示"未知"，请先查服务商价目。
- 视频生成失败或超时后，软件不会自动重复提交（避免重复扣费）；"结果未知"的任务需要你先到服务商后台核对账单再手动重试。
- 请勿把授权码、API Key、账号登录信息发给任何人或贴到群里。

## 7. 合规提醒
- **版权**：只学习爆款的"结构和节奏"，用你自己的产品和人物重新生成；不要搬运他人的画面、音乐、台词。软件默认不把参考视频的画面和音乐放进成片。
- **平台规则**：自动化发布存在被平台限流或封号的风险。新号先手动养号；多个账号请使用各自独立的代理；发布 AI 生成内容时请勾选 AI 标注。
- 因使用本软件产生的账号、版权或费用问题由使用者自行承担。

## 8. 常见问题
- **激活提示"绑定了其他电脑"**：授权码是按电脑发的，换电脑需重新向老师要。
- **杀毒软件报毒/拦截**：打包类程序偶尔误报，请把安装目录加入信任，或联系老师。
- **发布提示需要人工确认**：任务状态是"需要人工确认"时，说明结果未知，先到 TikTok 里确认视频是否真的发出，再选"标记完成"或确认后重试，避免重复发布。
- **更新**：软件启动时会检查新版本，提示后点"立即更新"，数据和配置会保留。
- **数据在哪**：Windows `%LOCALAPPDATA%\TikTolTool`，macOS `~/Library/Application Support/TikTolTool`。卸载软件不会删除这里的数据。
