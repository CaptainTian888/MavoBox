# MAVO BOX 教师/发行手册

## 一、两把密钥（最重要）
都在项目根目录的 `MavoBox-File/` 文件夹（已被 `.gitignore` 排除，**绝不能提交，也要另外备份**）：

| 文件 | 作用 | 丢了/泄露的后果 |
|---|---|---|
| `mavobox_license_private.pem` | 给学员签发授权码 | 丢了：老学员的码无法续期，只能换公钥重新发版并让所有人重装；泄露：任何人能自己造码 |
| `mavobox_updater.key`（及 `.pub`） | 给更新包签名 | 丢了：无法再发自动更新；泄露：别人可冒充更新 |

对应的公钥已内置：授权公钥在 `backend/core/license_key.py`，更新公钥在 `src-tauri/tauri.conf.json`。

## 二、给学员发授权码
学员在激活页拿到机器码后，在项目 `backend/` 目录运行（Windows PowerShell）：

```powershell
uv run python tools/license_tool.py issue --key ..\MavoBox-File\mavobox_license_private.pem --name "张三" --machine ABCDE-12345-FGHIJ-67890 --days 365
```

- `--machine` 填学员的机器码 = 只能在这台电脑用（推荐）；不填 = 不绑定电脑（谁拿到都能用，慎用）。
- `--days 365` 或 `--exp 2027-12-31` 控制有效期；都不写 = 永久。
- 输出的 `MAVO1.…` 整串发给学员。校验：`uv run python tools/license_tool.py check --code MAVO1.… --machine 机器码`。
- 离线授权不是防破解方案：能改程序的人可以绕过。它的目的是挡住随手转发。

## 三、发布新版本
1. 改 `backend/core/version.py`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml` 里的版本号（保持一致）。
2. **Windows**：`set FFMPEG_BIN_DIR=<含 ffmpeg.exe 与 ffprobe.exe 的目录>` → `scripts\build.cmd` → 在**普通终端**（不是 Claude 应用内置的沙箱）里设置 `TAURI_SIGNING_PRIVATE_KEY`（私钥内容或路径）后运行 `scripts\tauri-build.ps1`。
   产物在 `src-tauri\target\release\bundle\nsis\`：`.exe` 安装包、`.exe.sig` 更新签名。
3. **macOS**：必须在 Mac 上构建（或用 `.github/workflows/release.yml` 的 macOS runner）。`scripts/build.sh` → `npx @tauri-apps/cli@2 build --bundles dmg,app`。
4. 生成可上传的发布文件夹（自动改成不含空格的文件名、生成 `latest.json` 和校验和）：
```powershell
cd backend
uv run python ..\scripts\make_release.py --version 0.2.0 --base-url https://github.com/CaptainTian888/MavoBox/releases/download/v0.2.0 --notes "更新说明"
```
产物在项目根目录的 `release\v0.2.0\`：`MAVO-BOX_0.2.0_x64-setup.exe`、`.sig`、`latest.json`、`SHA256SUMS.txt`（该目录已被 `.gitignore` 排除）。
5. 发布到 GitHub Release（学员下载与应用自动更新共用同一处）：
   - 网页：仓库 → Releases → Draft a new release → Tag 填 `v0.2.0` → 把 `release\v0.2.0\` 里的 4 个文件全部拖进 Assets → Publish release。
   - 命令行（需先 `gh auth login`）：`gh release create v0.2.0 release\v0.2.0\* --title "MAVO BOX 0.2.0" --notes "更新说明"`。
6. 应用的更新地址写在 `src-tauri/tauri.conf.json` 的 `plugins.updater.endpoints`：`https://github.com/CaptainTian888/MavoBox/releases/latest/download/latest.json`。它指向**最新一个正式 Release** 里名为 `latest.json` 的文件，所以每次发版都必须把新的 `latest.json` 一起上传。仓库必须保持公开，应用才能读到。更新包有签名保护，公开托管不会让别人伪造更新；使用权仍由授权码控制。
7. 学员升级体验：启动时检查 → 弹窗"立即更新" → 下载并校验签名 → 静默安装（约 30 秒，后端文件较多）→ 自动重新打开。数据和配置保留。

### 更新流程测试（发版前建议跑一次）
`scripts	est-update.ps1` 会在本机临时目录里装旧版，用本地 http 服务当更新源，验证"发现更新 → 校验签名 → 安装 → 自动重启"全流程，结束后自动卸载清理。需要用 `src-tauri	est-base.json`（允许 http 更新源，仅测试用）构建旧版和新版：`scripts	auri-build.ps1 -Config src-tauri	est-base.json`。应用里保留了两个测试用环境变量：`MAVOBOX_UPDATE_URL`（换更新源，更新包仍必须有正确签名，且正式包只接受 https）和 `MAVOBOX_UPDATE_SILENT=1`（不弹确认框）。

## 四、分发前自检清单
- [ ] 用一台没装过任何开发工具的干净电脑/虚拟机安装，走完 激活 → 向导 → 一个下载任务。
- [ ] 检查安装包里 ffmpeg 已内置（向导页显示"已内置"）。
- [ ] 买代码签名证书（Windows）/ 苹果开发者账号（macOS）后再大范围发放，能明显减少"未知发布者"和杀毒误报。
- [ ] 第三方许可见 `THIRD_PARTY_NOTICES.md`：随安装包提供，并在分发页注明 ffmpeg 为 GPL 构建及其源码获取地址。
- [ ] 私钥已备份到离线位置。
